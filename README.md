# Pizzaria Joinvillense

Site simples de uma pizzaria de Joinville feito com HTML, CSS e JavaScript.

## Arquivos do projeto
- `index.html` - estrutura da página e formulário
- `css/style.css` - cores, estilos e adaptação para celular
- `js/script.js` - validação e cálculo do pedido
- `img/` - imagens usadas no site

## Regras do formulário
- O nome, o sabor e o tamanho não podem ficar vazios.
- A quantidade de pizzas deve ser entre 1 e 20.
- Pedidos com 3 pizzas ou mais ganham 10% de desconto.
- Entrega em Joinville soma R$ 10,00 no valor final.
